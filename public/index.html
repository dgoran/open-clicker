Open Clicker

Remote presenter control system

🎬 Producer

Create and manage a presentation session. Control the clicker lock, set timers, and manage speaker notes.

📱 Clicker

Join a session from your phone or computer. Advance slides with large, easy-to-tap buttons.

🖥️ Show Client (Browser)

Browser-based show client for testing. For production, use the Node.js CLI client to control desktop apps.
